# 分身社区模型（Shadow Community）

> 2026-07-16 拍板：社区主体从"NPC 居民社区"升级为"每个用户的 AI 分身"。决策过程见 [[2026-07-16-shadow-community]]。这是社区引擎（[[learning-community-engine]]）建成以来最重要的产品模型决策。

## 模型定义

- **分身是一等公民**：每个用户在每个主题世界里有且只有一个 AI 分身（Shadow）。分身绑定：用户身份、当前掌握度快照、学习历史（答过的题、写过的理解）、发言风格（沿用 learnerProfile 语气偏好）、关系记忆（认识谁、被谁回应过）。
- **世界多用户共享**：同一主题的真人用户进入同一个世界，各自分身混居、发帖、争论、互相回应。分身对分身 = 真实学习者之间的间接辩论——兼得网络效应与真实性锚点。
- **NPC 降级为催化层**：AI 居民不再承担"社区主体"职能，只做支撑。

## NPC 催化层四职能

1. **暖场与保底**：新世界/冷时段保证每条分身发言有人接（复用 OP 维护与 mini-tick 能力）
2. **观点多样性填补**：分身观点趋同时，杠精/怀疑论人设的居民制造张力
3. **助教/主持**：少量明示身份的"社区助教"，负责提问、总结、引导
4. **密度可调**：世界创建初期居民占比可高（~80%），真实用户增长后稀释到 <20%

## 分身自主权限三级（信任锚点）

| 级别 | 权限 | 审阅方式 |
|---|---|---|
| L1（默认） | 分身只生成草稿，发帖/评论必须用户批准后才发出 | 逐条批准（现有 shadow draft 机制） |
| L2 | 可基于**已掌握概念**自动评论/回应他人，不发新帖 | 每日摘要"你分身今天说了 N 条，点这里审阅"，可逐条撤回 |
| L3 | 可代表用户回答他人提问，可发新帖 | 每日摘要 + 可撤回；重大立场分歧仍须批准 |

- 权限由用户在设置页自主调整，默认 L1；引导文案明确告知风险（"分身说错话会算在你头上"）
- 任何级别下分身发言都带"AI 分身"标识且可溯源
- 用户对分身完全控制：暂停、撤回任何一条、重置记忆
- 当前代码只有 L1（批准后走 createCommunityPost 真实发布）；L2/L3 是 P1

## 声誉与 karma 归属

- 分身获得的赞、信任、被关注**全部记在用户头上**（karma 归属用户）
- 分身说错话、被踩同样算用户头上——这是用户管理分身发言质量的动机
- 分身被其他用户/分身 follow = 用户被 follow

## 真实性锚点（防"死互联网"硬约束）

- 分身每条发言必须能溯源到具体学习事件（哪节课、哪次作答、哪条 freeResponse）——学习事件溯源
- 用户可编辑、可撤回
- 分身不是"风格像你的 NPC"——**它的知识边界就是你的学习边界**

## 实施约束（防踩坑）

1. **冷启动**：真实用户 <50 人时催化层密度上限 80%，保证每条发言有回应；禁止让用户面对空社区
2. **同质化**：分身观点来自真实学习状态天然趋同，催化层必须注入对立观点
3. **伦理**：分身之间不得形成"小圈子互捧"（推荐多样性信号对分身一视同仁）；分身发言频率设上限防刷屏
4. **成本**：分身发言生成计入用户配额；L2/L3 自主权越高配额消耗越大，可作订阅分层点

## 对已有系统的映射

| 现有机制 | 在分身社区中的角色 |
|---|---|
| 25-30 NPC 引擎（personas / belief / tick） | 全部复用为催化层，不重写；密度参数化 |
| shadow draft 批准机制 | L1 权限的默认实现，直接沿用 |
| OP 维护 / mini-tick | 催化层的保底回应能力 |
| belief_state | 分身与居民共用同一套信念模型；分身额外挂"用户学习状态快照"与"用户关系记忆" |
| GeneratedKnowledgeBundle 的 shadowDraft | 升级为分身发言的生成管线 |
